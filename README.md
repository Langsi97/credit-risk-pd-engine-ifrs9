# Credit Risk PD Engine IFRS 9

This repository provides a starter structure for a credit risk scorecard and probability of default (PD) engine aligned with IFRS 9 workflows.

## Repository layout

- `data/` — local datasets and raw inputs (ignored by Git)
- `notebooks/` — exploratory analysis, model development, and validation notebooks
- `src/` — source code for modeling, feature engineering, and scoring logic
- `tests/` — unit and integration tests
- `reports/` — generated outputs such as model summaries, validation reports, and dashboards
- `.github/workflows/` — CI/CD automation

## Getting started

1. Add raw or processed datasets under `data/`.
2. Develop exploratory notebooks in `notebooks/`.
3. Implement reusable logic under `src/`.
4. Validate behavior with tests in `tests/`.
5. Save model outputs to `reports/`.
